# MarkLite 功能示例

> 一份用于验证编辑、预览与导出效果的中文样例文档。

![MarkLite](banner.png)

## 轻量，但不将就

MarkLite 使用 **Rust + egui** 构建，不捆绑浏览器运行时。它把注意力放回文字本身：
专注编辑、即时预览、干净导出。支持 *斜体*、**粗体**、~~删除线~~、`行内代码`，
以及 [外部链接](https://www.rust-lang.org/) 和上标^注^。

- 纯文本优先，文件始终在你手里
- 无账号、无云端依赖，离线也能工作

> “写作的第一要务，是让想法清晰地落纸。”
>
> 好的工具应该退到文字背后。

> [!TIP]
> 使用 `Ctrl + 2` 进入预览，`Ctrl + 3` 进入左右分栏。

### 有序步骤

1. 打开或新建一个 `.md` 文件
2. 在编辑区书写内容
3. 切换到预览检查排版
4. 通过“导出”保存为 PDF 或 Word

## 代码与表格

```rust
use std::fs;

fn main() -> std::io::Result<()> {
    let text = fs::read_to_string("note.md")?;
    println!("{}", text);
    Ok(())
}
```

| 能力 | 状态 | 说明 |
| :--- | :---: | ---: |
| 编辑 Markdown | ✅ | 原生文本编辑 |
| 实时预览 | ✅ | GFM 扩展 |
| 导出 PDF | ✅ | 依赖本机浏览器内核 |
| 导出 Word | ✅ | 原生 .docx |
